# Contributing

Thanks for helping improve MiniBot.

## Setup

1. Fork and clone the repo  
2. `npm install`  
3. `npm test` before opening a PR  

## Guidelines

- Keep plugins small and focused  
- Prefer offline mini-apps for UI; use APIs only when useful  
- No emojis in user-facing command text unless necessary  
- Do not commit `session/` or secrets  
- Match existing code style (CommonJS, minimal comments)

## Pull requests

- Describe what changed and how to test it  
- One logical change per PR when possible
